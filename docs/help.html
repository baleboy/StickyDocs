StickyDocs Help

Sticky notes on your desktop, each one backed by a Google Doc in your Drive.

Getting started

  1. Sign in. First launch shows a welcome screen and asks you to sign in with Google. The app uses the drive.file scope, which means it can only see Docs it creates itself — not the rest of your Drive.
  2. Pick a folder. After sign-in, choose a name for the Drive folder where your stickies will live (default: “Stickies”). The folder is created on first sync.
  3. Create a sticky. Click the StickyDocs icon in the menu bar → New Sticky, or use ⇧⌘N.

Day-to-day use

  • Menu bar icon. All actions (New Sticky, Show All Stickies, Sync Now, Open Stickies Folder in Drive, Sign In/Out, Updates) live in the menu bar dropdown.
  • All Stickies window. Lists every sticky and lets you re-open ones you’ve previously closed.
  • Formatting. Bold (⌘B), Italic (⌘I), Underline (⌘U), bulleted list, numbered list. No headings or images in v1.
  • Closing a sticky. Closing the window hides the sticky but keeps its data; reopen it from All Stickies.
  • Deleting a sticky. Right-click → Delete. You’ll be asked whether to also delete the Doc in Drive.

How sync works

  • Each sticky is one Google Doc in your chosen folder. The Doc is created on first edit — empty notes don’t litter your Drive.
  • Edits push to Drive after 1.5 seconds of inactivity, and immediately when the sticky loses focus or closes.
  • Edits made on docs.google.com pull back into the sticky on app launch and any time you trigger Sync Now.
  • Sync Now (menu bar) forces a full round-trip immediately.

Cross-machine

Sign in with the same Google account on a second Mac and the app will discover the stickies you created on the first one. Discovered stickies start closed — open the ones you want from All Stickies.

Unlinked stickies

If a sticky’s Doc gets deleted or trashed in Drive, the sticky stays on your Mac but its status dot turns red and the banner explains what happened. Right-click → Re-create Doc in Drive to provision a new Doc with the current local content.

Conflicts

If both sides change a sticky between syncs, remote wins and the local version is stashed in a backup. Right-click → Restore Backup to swap it back.

Updates

The app auto-checks for updates daily. To get pre-release builds, toggle Receive Alpha Updates in the menu bar. Alpha builds are less stable than stable ones — opt in only if you’re comfortable with that.

Privacy

  • Tokens are stored in the macOS Keychain.
  • The drive.file scope means the app has access only to Docs it created and folders it manages. It cannot read the rest of your Drive.
  • No analytics, no telemetry, no third-party services beyond Google’s APIs.

Reporting a bug

Help → Report an Issue… opens the GitHub issues page. Include your macOS version, the app version (About StickyDocs shows it), and steps to reproduce.
